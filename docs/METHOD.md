# 设计与方法

本文区分三类内容：**原论文方法**指 SPA-RL 的研究方案，**项目笔记**指本次整理的本地设计材料，**整理建议**指为了后续复现而提出的记录要求。项目笔记不等同于运行证据。

## 任务背景

网页购物是一个连续决策任务。智能体需要理解商品需求，在多个页面中选择搜索词、浏览商品、调整选项并完成模拟购买。单次动作看似合理，并不保证最后选择的商品满足全部约束。

WebShop 提供基于商品信息与文字指令的模拟环境，主要交互包括搜索和点击。它适合研究多步决策；项目笔记中提到的真实手机助手、应用操作和支付属于应用动机，现有材料没有这些功能的实现证据。环境定义参见 [WebShop 原论文](https://arxiv.org/abs/2207.01206)。

## 原论文方法

SPA-RL 研究终局奖励难以指导中间动作的问题。它训练进度评估器，将轨迹结果与各步贡献联系起来，再将进度贡献和动作可执行性信号结合，服务于策略优化。该方法及其论证来自 [SPA-RL 原论文](https://arxiv.org/abs/2505.20732v1)，并非本项目提出的新算法。

## 项目笔记中的设计链路

| 阶段 | 笔记描述 | 后续需要核实的内容 |
| --- | --- | --- |
| 轨迹准备 | 将任务、观察、思考文本与动作整理为对话记录 | 数据来源、许可、任务编号、划分清单，以及思考文本的生成方式 |
| 监督微调 | 使用 Llama 系列约 3B 参数模型与 LoRA 学习示范轨迹 | 精确模型名称、输入模板、损失掩码、训练参数与检查点 |
| 进度评估 | 在模型上增加轻量预测模块，估计每一步的贡献 | 输入定义、回归目标、标签来源与训练数据 |
| 策略优化 | 将逐步反馈用于 PPO 训练 | 奖励公式、终局奖励处理、优势计算、约束项与训练日志 |
| 环境评测 | 使用模型服务与环境交互，统计购物结果 | 环境版本、测试任务、终止条件、失败处理与逐任务奖励 |

以上描述保留了笔记的研究路线，但没有据此推断每个阶段已经运行成功。

## 与原方法的区别需要逐项记录

原论文使用 `Llama-3.2-3B-Instruct`；笔记主要写作“Llama-3B”，精确版本未由模型配置证实。原论文将逐步进度与动作可执行性信号结合，而笔记中还出现将动作项固定为 1 的简化表述。若实际实现采用该简化，应说明适用环境和公式，不能直接称为完整复现。

数据划分、评测阈值和测试集规模也需要与原论文分别记录，详见[实验记录与核验](EXPERIMENTS.md)。

## 整理建议：先让结果可追溯

每次实验应绑定代码提交、完整配置和测试任务列表，再保存模型输出与环境返回的奖励。这样才能区分性能变化来自训练方法、任务难度、环境版本还是成功判定阈值。该建议用于后续补充材料，不表示本仓库已有这些实验。
